# Online Shopping Pattern Analyzer

This project explores an online shopping dataset to understand how customers shop, which product categories perform best, how demand changes across seasons, and how customers can be grouped based on their purchasing behavior.

# Objective
The main goal of this project is to find useful patterns in shopping data and turn them into insights that can help businesses make better decisions related to marketing, inventory planning, and customer engagement.

# Tools and Techniques
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Exploratory Data Analysis (EDA)
- K-Means Clustering
- Association Rule Mining

# What I Did
- Cleaned and prepared a dataset of 3,900 online shopping records
- Handled missing values, removed duplicates, standardized product categories, and formatted dates
- Performed exploratory data analysis to understand overall purchasing patterns
- Created visualizations to study category-wise sales, seasonal demand, and customer behavior
- Used K-Means clustering to group customers based on their spending and purchase patterns
- Applied association-rule mining to find products that are often purchased together

# Key Insights
- Clothing was the top-selling category and contributed 43.8% of total sales.
- Seasonal demand patterns were observed, which can help businesses plan fashion products and promotions.
- Product combinations such as mobile phones with phone covers, shoes with socks, and laptops with mice showed potential for cross-selling.
